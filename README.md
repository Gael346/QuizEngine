# MathQuiz
The project is a terminal program that, when run, generates a math quiz that you can customize.

# Project and Objective
I'm Gael, and I'm learning through small projects. For this project, I wanted to review and expand my 
Python knowledge and use mathematical functions.

The problem I encountered was that I had a less-than-ideal way of storing the answer in a dictionary for the multiple-choice question, 
since I needed a duplicate in a list within the dictionary. But then I realized I could fix it by using a tuple.

# Clone and run 
Clone and Run
Clone the repository: HTTPS: git clone https://github.com/Gael346/QuizEngine.git

Or SSH: git clone git@github.com:Gael346/QuizEngine.git

Enter the folder and run: cd QuizEngine

python MathQuiz.py

# Features
- Create test quiz
- Create normal quiz
- Select difficulty
- Select number of questions
- Select number of options in type test
- Note , from 0 to 10

# Technologies
- Written in python
- Randomly generated questions
- Dicts , lists and tuple
